## URL del contenedor

Servicio de proxy inverso que expone los subdominios *.antoniogatfdezpruebas.es (no tiene una URL de aplicación propia específica).

## Pasos para reproducirlo

1. Entra en este directorio:
   cd caddy
2. Levanta el contenedor de Caddy que actuará como reverse proxy para el resto de servicios:
   docker compose up

## Comando para ejecutar el Docker Compose

Desde el directorio caddy:

docker compose up
