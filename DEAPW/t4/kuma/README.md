## URL del contenedor

https://kuma.antoniogatfdezpruebas.es/

## Pasos para reproducirlo

1. Asegurarse de tener el contenedor de Caddy encendido.
2. Entra en este directorio:
   cd kuma
3. Levanta el contenedor de Uptime Kuma:
   docker compose up
4. Accede en el navegador a:
   https://kuma.antoniogatfdezpruebas.es/

## Comando para ejecutar el Docker Compose

Desde el directorio kuma:

docker compose up
