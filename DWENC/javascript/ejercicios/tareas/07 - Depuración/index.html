🐛 Ejercicio de Depuración JavaScript

📋 Instrucciones

Este ejercicio está diseñado para practicar el uso del depurador de JavaScript.

Debes abrir las Herramientas de Desarrollador (F12) y usar el depurador para:

  • Poner puntos de interrupción (breakpoints)
  • Inspeccionar variables
  • Evaluar expresiones
  • Usar Step Over (F10), Step Into (F11), Step Out (Shift+F11)

⚠️ IMPORTANTE: Si fallas un reto, tendrás que empezar desde el principio.
